⚡ TLS vs mTLS – résumé entretien

🔵 TLS – Transport Layer Security

  • 🔒 Chiffre le trafic entre client et serveur.
  • 🧭 Le serveur prouve son identité via son certificat.
  • 🛡️ Garantit l’intégrité des données.
  • ➡️ Exemple : navigateur ↔️ site web (https://).

🟣 mTLS – Mutual TLS

  • Tout ce que fait TLS ✅
  • + le client présente aussi un certificat.
  • 🔐 Authentification serveur + client.
  • ➡️ Exemple : API internes, microservices, environnement bancaire/PKI.

🧠 Phrase entretien : « TLS = le serveur prouve qui il est, mTLS = le serveur et le client prouvent qui ils sont. »

🎤 Phrase type : pourquoi SoftHSM2 en dev et HSM en prod ?

« En environnement de développement, nous utilisons SoftHSM2 qui simule un HSM matériel via PKCS#11. Le HSM physique est coûteux et réservé aux environnements de pré-production/production, où il doit respecter des exigences de sécurité et de certification (FIPS, eIDAS, RGS). SoftHSM2 nous permet de développer et tester sans manipuler de clés réellement sensibles, avec le même code côté application. En production, les clés privées sont générées directement dans le HSM et sont non-exportables. »
