# README: Classe `MfaEnableRequest`

Ce fichier explique le rôle et l'utilité de la classe `MfaEnableRequest.java`.

---

## 🇫🇷 Français

### 👔 Explication Professionnelle

`MfaEnableRequest` est un DTO (Data Transfer Object) utilisé pour encapsuler les données nécessaires à l'activation de l'authentification multi-facteurs (MFA) pour un utilisateur. Ce DTO est envoyé par le client après qu'un secret TOTP ait été généré et que l'utilisateur ait configuré son application d'authentification. Il contient le `secret` TOTP qui a été initialement fourni à l'utilisateur (pour confirmation) et le `code` TOTP généré par l'application d'authentification de l'utilisateur. Le serveur utilisera ces informations pour vérifier que le secret est correct et que le code TOTP est valide avant d'activer le MFA pour l'utilisateur.

### 🧒 Explication pour un enfant

Imagine que `MfaEnableRequest` est comme un formulaire que tu remplis pour dire à l'application : "Je suis prêt à activer ma super serrure !". Dans ce formulaire, tu écris le "code secret" que l'application t'a donné au début, et aussi le petit code à 6 chiffres que ton application d'authentification te montre maintenant. L'application vérifie que tout est bon, et si c'est le cas, elle active ta super serrure.

---

## 🇬🇧 English

### 👔 Professional Explanation

`MfaEnableRequest` is a DTO (Data Transfer Object) used to encapsulate the data required to enable Multi-Factor Authentication (MFA) for a user. This DTO is sent by the client after a TOTP secret has been generated and the user has configured their authenticator app. It contains the `secret` TOTP that was initially provided to the user (for confirmation) and the `code` TOTP generated by the user's authenticator app. The server will use this information to verify that the secret is correct and that the TOTP code is valid before enabling MFA for the user.

### 🧒 Kid's Explanation

Imagine `MfaEnableRequest` is like a form you fill out to tell the app: "I'm ready to activate my super lock!". In this form, you write the "secret code" that the app gave you at the beginning, and also the small 6-digit code that your authenticator app is showing you now. The app checks that everything is correct, and if so, it activates your super lock.

## 🇸🇦 العربية

### 👔 شرح احترافي

`MfaEnableRequest` هو كائن نقل بيانات (DTO) يستخدم لتغليف البيانات المطلوبة لتفعيل المصادقة متعددة العوامل (MFA) لمستخدم. يتم إرسال هذا الكائن من قبل العميل بعد إنشاء سر TOTP وقيام المستخدم بتكوين تطبيق المصادقة الخاص به. يحتوي على `secret` TOTP الذي تم توفيره للمستخدم في البداية (للتأكيد) و `code` TOTP الذي تم إنشاؤه بواسطة تطبيق المصادقة الخاص بالمستخدم. سيستخدم الخادم هذه المعلومات للتحقق من صحة السر وصحة رمز TOTP قبل تفعيل MFA للمستخدم.

### 🧒 شرح لطفل

تخيل أن `MfaEnableRequest` يشبه نموذجًا تملأه لتقول للتطبيق: "أنا جاهز لتفعيل قفلي الفائق!". في هذا النموذج، تكتب "الرمز السري" الذي أعطاك إياه التطبيق في البداية، وأيضًا الرمز الصغير المكون من 6 أرقام الذي يظهره لك تطبيق المصادقة الخاص بك الآن. يتحقق التطبيق من أن كل شيء صحيح، وإذا كان الأمر كذلك، فإنه يقوم بتفعيل قفلك الفائق.
