# README: Classe `UserCreateDto`

Ce fichier explique le rôle et l'utilité de la classe `UserCreateDto.java`.

---

## 🇫🇷 Français

### 👔 Explication Professionnelle

`UserCreateDto` est un DTO (Data Transfer Object) spécifiquement conçu pour encapsuler les données nécessaires à la création d'un nouvel utilisateur via l'API. Il contient les champs `username`, `email`, `password` et `roles`. L'utilisation de ce DTO permet de valider les données entrantes avant de les mapper vers l'entité `User` du domaine. Il assure une séparation claire entre le modèle de données de l'API et le modèle de données interne, et garantit que seuls les champs autorisés pour la création sont acceptés. La méthode `toEntity()` facilite la conversion du DTO en une entité `User` prête à être persistée, en laissant l'ID être généré par le système.

### 🧒 Explication pour un enfant

Imagine que `UserCreateDto` est comme un formulaire que tu remplis quand tu veux t'inscrire pour la première fois au château. Tu dois donner ton nom, ton email, et choisir un mot de passe secret. Tu peux aussi dire quel travail tu veux faire (tes rôles). Ce formulaire est spécial car il s'assure que tu donnes toutes les informations nécessaires pour créer ta carte d'identité, mais il ne te demande pas de choses inutiles ou dangereuses.

## 🇬🇧 English

### 👔 Professional Explanation

`UserCreateDto` is a DTO (Data Transfer Object) specifically designed to encapsulate the data required for creating a new user via the API. It contains the `username`, `email`, `password`, and `roles` fields. Using this DTO allows for validation of incoming data before mapping it to the domain `User` entity. It ensures a clear separation between the API's data model and the internal data model, and guarantees that only fields authorized for creation are accepted. The `toEntity()` method facilitates the conversion of the DTO into a `User` entity ready for persistence, allowing the ID to be generated by the system.

### 🧒 Kid's Explanation

Imagine `UserCreateDto` is like a form you fill out when you want to sign up for the castle for the first time. You need to give your name, email, and choose a secret password. You can also say what job you want to do (your roles). This form is special because it makes sure you provide all the necessary information to create your ID card, but it doesn't ask for unnecessary or dangerous things.

## 🇸🇦 العربية

### 👔 شرح احترافي

`UserCreateDto` هو كائن نقل بيانات (DTO) مصمم خصيصًا لتغليف البيانات المطلوبة لإنشاء مستخدم جديد عبر واجهة برمجة التطبيقات (API). يحتوي على حقول `username` و `email` و `password` و `roles`. يتيح استخدام هذا الكائن التحقق من صحة البيانات الواردة قبل تعيينها إلى كيان `User` الخاص بالمجال. يضمن فصلًا واضحًا بين نموذج بيانات API ونموذج البيانات الداخلي، ويضمن قبول الحقول المصرح بها للإنشاء فقط. تسهل الدالة `toEntity()` تحويل كائن نقل البيانات إلى كيان `User` جاهز للحفظ، مما يسمح للنظام بتوليد المعرف.

### 🧒 شرح لطفل

تخيل أن `UserCreateDto` يشبه نموذجًا تملأه عندما تريد التسجيل في القلعة لأول مرة. تحتاج إلى إعطاء اسمك وبريدك الإلكتروني واختيار كلمة مرور سرية. يمكنك أيضًا تحديد الوظيفة التي تريد القيام بها (أدوارك). هذا النموذج مميز لأنه يتأكد من أنك تقدم جميع المعلومات الضرورية لإنشاء بطاقة هويتك، ولكنه لا يطلب منك أشياء غير ضرورية أو خطيرة.
