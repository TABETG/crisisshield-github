# README: Classe `MfaVerificationRequest`

Ce fichier explique le rôle et l'utilité de la classe `MfaVerificationRequest.java`.

---

## 🇫🇷 Français

### 👔 Explication Professionnelle

`MfaVerificationRequest` est un DTO (Data Transfer Object) utilisé pour encapsuler les données envoyées par le client lorsqu'il souhaite vérifier un code TOTP. Ce DTO est typiquement utilisé dans deux scénarios :
1.  **Activation du MFA** : Après avoir scanné le QR code et configuré son application d'authentification, l'utilisateur doit fournir un premier code TOTP pour confirmer que la configuration est correcte et activer le MFA sur son compte.
2.  **Connexion avec MFA** : Si le MFA est déjà activé pour l'utilisateur, ce DTO est utilisé pour fournir le code TOTP requis après l'authentification par mot de passe, afin de finaliser le processus de connexion.

Il contient un seul champ, `code`, qui représente le code TOTP à 6 ou 8 chiffres généré par l'application d'authentification de l'utilisateur.

### 🧒 Explication pour un enfant

Imagine que `MfaVerificationRequest` est comme un petit message que tu envoies à l'application pour lui dire : "Regarde, j'ai le bon code secret de mon application !". Ce message contient juste le code à 6 chiffres que ton application d'authentification te montre. L'application vérifie si c'est le bon code pour te laisser entrer ou pour activer ta super serrure.

## 🇬🇧 English

### 👔 Professional Explanation

`MfaVerificationRequest` is a DTO (Data Transfer Object) used to encapsulate data sent by the client when they want to verify a TOTP code. This DTO is typically used in two scenarios:
1.  **MFA Activation**: After scanning the QR code and configuring their authenticator app, the user must provide an initial TOTP code to confirm that the setup is correct and activate MFA on their account.
2.  **Login with MFA**: If MFA is already enabled for the user, this DTO is used to provide the required TOTP code after password authentication, to finalize the login process.

It contains a single field, `code`, which represents the 6 or 8-digit TOTP code generated by the user's authenticator app.

### 🧒 Kid's Explanation

Imagine `MfaVerificationRequest` is like a small message you send to the app to tell it: "Look, I have the right secret code from my app!". This message just contains the 6-digit code that your authenticator app shows you. The app checks if it's the right code to let you in or to activate your super lock.

## 🇸🇦 العربية

### 👔 شرح احترافي

`MfaVerificationRequest` هو كائن نقل بيانات (DTO) يستخدم لتغليف البيانات المرسلة من العميل عندما يرغب في التحقق من رمز TOTP. يستخدم هذا الكائن عادة في سيناريوهين:
1.  **تفعيل MFA**: بعد مسح رمز الاستجابة السريعة وتكوين تطبيق المصادقة الخاص به، يجب على المستخدم تقديم رمز TOTP أولي لتأكيد صحة التكوين وتفعيل MFA على حسابه.
2.  **تسجيل الدخول باستخدام MFA**: إذا تم تفعيل MFA بالفعل للمستخدم، يتم استخدام هذا الكائن لتوفير رمز TOTP المطلوب بعد المصادقة بكلمة المرور، لإنهاء عملية تسجيل الدخول.

يحتوي على حقل واحد فقط، `code`، والذي يمثل رمز TOTP المكون من 6 أو 8 أرقام الذي تم إنشاؤه بواسطة تطبيق المصادقة الخاص بالمستخدم.

### 🧒 شرح لطفل

تخيل أن `MfaVerificationRequest` يشبه رسالة صغيرة ترسلها إلى التطبيق لتقول له: "انظر، لدي الرمز السري الصحيح من تطبيقي!". تحتوي هذه الرسالة فقط على الرمز المكون من 6 أرقام الذي يظهره لك تطبيق المصادقة الخاص بك. يتحقق التطبيق مما إذا كان الرمز صحيحًا للسماح لك بالدخول أو لتفعيل قفلك الفائق.
